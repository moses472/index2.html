SHOPNAIJA E-COMMERCE DEMO
========================
Built with HTML, CSS, and vanilla JavaScript.

Pages:
- index.html: homepage, carousel, category icons, flash sales, product listing and search
- product.html: blender product detail, seller, delivery, specs, feedback and related products
- cart.html: cart quantity controls and remove items
- checkout.html: demo checkout form and totals
- account.html: account overview
- help.html: help centre and FAQ accordion
- login.html: demo login
- register.html: demo registration
- css/style.css: responsive styling and animations
- js/app.js: product data, search, localStorage cart and interactions

Run:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser. Live Server is recommended.
4. Keep css and js folders alongside the HTML files.

Notes:
Font Awesome, Google Fonts and images load online. Cart data uses browser localStorage.
Login/register/support and checkout are demonstrations only. There is no backend or real payment processing.
Sample product prices, ratings and listing details are illustrative and not verified current offers.
